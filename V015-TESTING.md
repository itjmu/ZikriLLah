# ZikriLLah 0.15 — уведомления и бот

## Что изменилось
- APK: ежедневное локальное напоминание, по умолчанию 07:00 по времени телефона. Интернет и подключение Telegram для него не нужны.
- Android 12+: меню → настройки → время напоминания → «Точное время: разрешение». Разрешите будильники; отдельно разрешите уведомления. Без разрешения точного времени Android может задерживать напоминание.
- «Проверить уведомление без интернета» проверяет разрешение и канал уведомлений немедленно. Для проверки планировщика установите время на две минуты вперёд, включите авиарежим и заблокируйте телефон.
- После перезагрузки расписание восстанавливается. После принудительной остановки через настройки Android нужно открыть приложение. Ограничения батареи производителя могут мешать доставке.
- Бот: настройки → напоминание. По умолчанию 07:00, часовой пояс профиля (изначально UTC+5). Можно отключить, выбрать время и изменить пояс. Бот должен работать на сервере; Telegram требует интернет для получения сообщения.
- Админ-уведомления больше не исчезают через 24 часа. APK показывает каждое один раз при получении; уже показанные ID сохраняются. Администратор может удалить уведомление из будущей доставки.
- Открытый APK проверяет публичные уведомления раз в 30 секунд, без отправки счётчика. Закрытый APK получает их при синхронизации. Мгновенный фоновый push требует отдельной настройки Firebase; она пока не выполнена.
- Админ-панель: обзор, рассылки, публикация, оформление/уведомления. Цветные кнопки Telegram. Рассылки: предпросмотр, удаление последнего сообщения черновика, пауза, продолжение, остановка, отчёт доставки.
- Telegram-рассылка копирует оригиналы и сохраняет поддерживаемое Telegram оформление, медиа и альбомы. Защищённые и служебные сообщения, платежи и некоторые специальные форматы нельзя скопировать. APK/веб получают текстовую сводку, оригиналы медиа остаются в Telegram.

## Проверка
1. Установить dist/ZikriLLah-debug.apk поверх прежней версии, не удаляя данные.
2. Проверить локальное напоминание в авиарежиме, повторить после перезагрузки.
3. Создать админ-уведомление тестовым ботом: открытый APK получает его в течение примерно 30 секунд. Повторная синхронизация не дублирует его.
4. Офлайн-телефон синхронизировать спустя сутки: не удалённое администратором уведомление должно прийти.
5. В тестовом боте проверить настройки напоминания, часовой пояс, выключение/включение.
6. Для рассылки сначала проверить предпросмотр. Кнопка «Отправить всем» действительно отправляет всем пользователям этого бота. Использовать тестового бота.
7. Поставить рассылку на паузу, затем продолжить: уже доставленные сообщения повторно не отправляются. Уже отправленный запрос может завершиться после паузы.

## Обновление сервера
Dockerfile и docker-compose.yml сохранены. Использовать прежнюю инструкцию DOCKER.md, резервную копию data и существующий серверный .env. Тестовый токен и временный URL компьютера не переносить в production. Новая таблица daily_reminders создаётся автоматически, существующие данные не удаляются. APK подключать к тому же серверу, что и production-бот.

Документация платформ: https://developer.android.com/develop/background-work/services/alarms и https://core.telegram.org/bots/api#inlinekeyboardbutton.
