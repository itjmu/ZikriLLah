# ZikriLLah 0.17

## Готово
- В APK встроена предоставленная картинка без изменения изображения.
- Основной сервер: https://zikrillah.duckdns.org.
- APK с прежним адресом *.trycloudflare.com переключается на постоянный сервер. Старый тестовый токен удаляется; нужно один раз подключить Telegram через боковое меню. История сохранена, все записи поставлены в очередь для объединения с сервером. Привязка к прежнему Telegram ID защищает историю от смешивания аккаунтов. Другие пользовательские адреса не заменяются.
- Подтверждение выхода одно, без текста о синхронизации. Онлайн запускается обмен; через максимум 2,5 секунды интерфейс закрывается, даже если сервер не ответил. Неотправленные события остаются в очереди. Браузер может запретить закрытие вкладки программно; тогда её можно закрыть вручную.

## Сервер
Сохранить резервную копию data и production .env; выполнить git pull и docker compose up -d --build по DOCKER.md. Docker-конфигурация не менялась. В production .env должно быть PUBLIC_URL=https://zikrillah.duckdns.org. Пересоздание контейнера перечитывает .env. Локальный .env с тестовым ботом не переносить на сервер.

## Следующая иконка через бота
1. /admin → APK / веб → Иконка следующего APK.
2. Отправить PNG/JPG/WebP до 5 МБ (лучше как файл), проверить предпросмотр и подтвердить.
3. На компьютере для сборки выполнить:

    node scripts/prepare-app-icon.mjs --server https://zikrillah.duckdns.org
    powershell -NoProfile -ExecutionPolicy Bypass -File scripts/build-android.ps1

Можно также передать скрипту путь к локальной картинке. Он переносит оригинальные байты изображения в ресурс APK. При каждом выпуске увеличить versionCode/versionName в android/app/build.gradle, использовать прежний ключ подписи и раздать обновлённый APK. Без установки обновления произвольная новая launcher-иконка не меняется. Синхронизация сама не устанавливает APK.

## Проверка
Установить dist/ZikriLLah-debug.apk поверх прежней версии. Проверить иконку, адрес сервера, однократное подтверждение выхода в авиарежиме и при недоступном сервере. Подключить настоящий Telegram-бот и проверить объединение истории. Не удалять приложение перед обновлением.
