# ZikriLLah · v0.13

**Версия 0.13:** [Docker, вход через Telegram и новое расписание синхронизации](DOCKER.md). Автоматически в 07:00, 12:00, 22:00 + вручную кнопкой Telegram. Прежний лимит пяти попыток отменён.

**Администратору сервера:** [пошаговое развёртывание, перенос, HTTPS, резервирование и обновление](SERVER-DEPLOYMENT.md). Готовые конфигурации — в `deploy/`. Исторические разделы ниже описывают прежние версии; для установки используйте эту инструкцию.

На главном экране веба и Android — только зикр, круг-счётчик и кнопка меню. Экран не прокручивается; жесты масштабирования на области счётчика отключены. Один тап внутри или вне круга даёт одну запись. Защита от повторных нажатий по умолчанию 200 мс; в настройках доступны 100/200/350/500 мс. Боковое меню разделено на настройки, статистику, зикры, язык (русский/English) и темы (светлая, тёмная, чёрная, изумрудная).

Офлайн-тасбих: Android, веб / Telegram Mini App и Telegram-бот. Общий дизайн с чётками, четыре темы, русский и английский интерфейс, 12 готовых зикров и свои зикры, цель круга от 1 до 100000, настраиваемая дневная цель, вибрация, статистика за сегодня/вчера/месяц и личные отметки прогресса. В меню можно скрыть текст и включить автоматическую смену зикра после круга. Каждое нажатие записывается с уникальным ID; повторные отправки не увеличивают результат. Смена цели не удаляет историю. Цели и настройки интерфейса индивидуальны для устройства; история зикров общая.

## Единый запуск бота, API и веба

Главный экран веба и Android рассчитан на телефон: короткое нажатие на любую область приложения добавляет один зикр. Меню и открытые диалоги исключены; прокрутка, удержание и мультитач не считаются. Все настройки находятся в боковом меню ☰. Android запрашивает портретную ориентацию. PWA также объявляет портретную ориентацию в манифесте; в обычной вкладке браузера ориентацией управляет браузер/система.

Перед запуском заполните BOT_TOKEN в .env. Остановите прежние процессы бота и отдельного API. Теперь npm start запускает всё одним процессом; повторно npm run bot запускать не надо. Для отдельного локального теста только API существует npm run server. HTTPS-адрес/туннель для телефона по-прежнему нужен.

Требуется Node.js 22.18+ (SQLite встроен, пока имеет статус experimental). Внешних npm-зависимостей нет.

```powershell
npm.cmd start
```

Откройте http://localhost:3000. После первого успешного открытия веб-приложение доступно офлайн на этом же адресе. За пределами localhost для service worker нужен HTTPS. Данные хранятся в localStorage: очистка данных браузера удалит несинхронизированный прогресс.

## Telegram и общий аккаунт

1. Создайте бота через @BotFather, скопируйте `.env.example` в `.env` и заполните `BOT_TOKEN`.
2. Разместите сервер на постоянном хостинге с HTTPS, укажите адрес в `PUBLIC_URL`. За reverse proxy при необходимости установите `HOST=0.0.0.0`; публичный доступ к Node без HTTPS не используйте.
3. Запустите `npm.cmd start` и в отдельном терминале `npm.cmd run bot` из корня проекта с общим `DATA_DIR`.
4. Напишите боту `/start`. Кнопка откроет Mini App. `/link` выдаёт одноразовый код на 10 минут. Введите отдельный код на каждом устройстве. Код привязывает локальный прогресс к аккаунту отправителя команды.
5. `/stats` показывает суммарный прогресс. `/subhanallah`, `/alhamdulillah`, `/allahuakbar` добавляют зикр прямо из бота.

### Кнопки Telegram-бота

После `/start` меню отображается инлайн-кнопками под сообщением. «Начать зикр» открывает одну большую кнопку с названием зикра на нижней клавиатуре. Каждое её нажатие добавляет запись; остальные действия остаются инлайн. Бот удаляет входящие сообщения-нажатия и меняет текст одного сохранённого счётчика. Если сообщение со счётчиком удалено, бот создаёт его заново. Изменение самой нижней клавиатуры требует служебного сообщения; старое служебное сообщение удаляется. При недоступности Telegram очистка и обновление могут задерживаться. При выходе из практики, переходе в меню или `/stop` нижняя клавиатура убирается. После автоматической смены зикра меняется и подпись кнопки. Точную высоту клавиатуры задаёт клиент Telegram. В настройках доступны выбор зикра, цель круга, дневная цель, автоматическая смена зикра, скрытие текста и часовой пояс. `/daily 750` задаёт свою дневную цель; `/timezone +5:30` — смещение личной статистики. По умолчанию UTC+5; настройки бота отдельны от телефона.

Личная статистика: сегодня, вчера, 7 дней, месяц, всё время, серия активных дней, лучший день, распределение по зикрам, первая/последняя запись и текстовый график за неделю. Бот учитывает общую синхронизированную историю.

Рейтинги: сегодня, последние 7 календарных дней и всё время, топ-10 и своё место; периоды едины для всех — UTC. Одинаковый результат даёт одинаковое место. Участие выключено по умолчанию и включается самим пользователем после объяснения, что имя Telegram и итоговое количество будут публичными. После выхода новые рейтинги не включают пользователя; ранее отправленные снимки рейтинга могут остаться в чатах. Подробная статистика и точное время активности других людей не раскрываются. Результаты основаны на записях пользователей, это не защищённое от накрутки соревнование.

Для проверки нового интерфейса остановите только локальный процесс этого бота через Ctrl+C, запустите `npm.cmd run bot` и отправьте `/start`. Не запускайте две копии long polling для одного токена. Разработка версии 0.5 не изменяет проекты на Linux-сервере.

Бот работает через long polling; ранее установленный webhook нужно отключить перед запуском. Токен бота хранится только на сервере. Mini App намеренно использует явную привязку кодом, а не доверяет данным пользователя из браузера. Автоматический вход через Telegram initData пока не реализован.

## Android

Откройте папку `android` в Android Studio. Нужны JDK 17, Android SDK 35 и Android Gradle Plugin 8.7.3. Gradle wrapper включён и использует Gradle 8.11.1. Затем Build → Build APK(s). Минимальная версия Android — 8.0.

На этом компьютере Java 17 подготовлена в `.tools` из [официального архива Microsoft](https://learn.microsoft.com/en-us/java/openjdk/download); SHA256 архива проверен. Сборка из корня проекта:

```powershell
powershell -ExecutionPolicy Bypass -File scripts/build-android.ps1
```

Команда собирает debug APK, запускает unit-тесты и Android Lint. Результат копируется в `dist/ZikriLLah-debug.apk`. Инструкция установки и проверки на телефоне: [ANDROID-TEST.md](ANDROID-TEST.md). Каталог `.tools` не хранится в Git; на другом компьютере задайте `JAVA_HOME` и `ANDROID_HOME` и запустите `.\gradlew.bat assembleDebug` из папки `android`.

Android — отдельное нативное Java-приложение. Работает без сервера с первого запуска. История, очередь и настройки хранятся в SQLite; записи старой версии автоматически переносятся из SharedPreferences при обновлении APK поверх предыдущего. Новые нажатия и подтверждения сервера изменяют БД транзакционно, поэтому фоновая синхронизация не заменяет историю устаревшим снимком.

Один раз откройте меню → «Подключить Telegram», введите HTTPS-адрес сервера и код `/link`. Ручной кнопки синхронизации нет. После привязки отправка запускается:

- при открытии приложения и каждые 30 секунд на экране;
- через 2,5 секунды после начала серии нажатий;
- при восстановлении подтверждённого подключения к интернету;
- при уходе приложения с экрана;
- через постоянные задачи Android JobScheduler, в том числе после перезагрузки телефона.

Фоновая задача требует сеть и планируется после сворачивания APK: до 5 попыток за сутки. После ошибки повтор возможен не раньше чем через 15 минут и в пределах дневного лимита. Это не точное расписание. Android может отложить работу из-за Doze, экономии батареи или ограничений производителя. После принудительной остановки через настройки Android задачи возобновляются при открытии приложения. Очередь сохраняется до успешного ответа сервера. Веб-версия автоматически отправляет очередь при нажатиях, появлении сети и возвращении на страницу; закрытый браузер не гарантирует фоновую отправку.

## Проверка

```powershell
npm.cmd test
```

Проверяются объединение двух устройств, отсутствие дублей, изоляция аккаунтов, срок действия кодов, сохранение после перезапуска, новые нажатия во время HTTP-запроса, календарные границы и круги. Android unit-тесты отдельно проверяют статистику и часовой пояс. Работа фоновых задач на реальном телефоне проверяется по `ANDROID-TEST.md`.

## Структура и ограничения прототипа

- `web/` — адаптивный интерфейс и офлайн-кеш.
- `android/` — нативное приложение.
- `bot/` — Telegram long polling.
- `server/` — HTTP API и SQLite; данные в `data/zikrillah.sqlite`.
- `test/` — тесты синхронизации.

Это версия для разработки, не завершённый публичный сервис. Полная история передаётся при синхронизации; для больших объёмов нужны курсорная синхронизация и IndexedDB для веба. Пока нет отзыва сессий, смены аккаунта, удаления истории, лимитов запросов, автоматических резервных копий и редактирования/удаления пользовательских зикров. Перед публичным запуском добавить эксплуатационные механизмы и настроить HTTPS/резервирование. Не храните `.env` и `data/` в Git.

Официальная документация: [Telegram Mini Apps](https://core.telegram.org/bots/webapps), [AGP 8.7](https://developer.android.com/build/releases/agp-8-7-0-release-notes), [Android JobScheduler: сеть, повторение и сохранение задач](https://developer.android.com/reference/android/app/job/JobInfo.Builder), [отслеживание доступности сети](https://developer.android.com/reference/android/net/ConnectivityManager.NetworkCallback).

До 200 своих зикров на аккаунт. Они работают офлайн и объединяются после привязки и синхронизации; другим пользователям не показываются. Цель круга — любое целое число от 1 до 100000, настройка отдельная для каждого устройства.

В боте «Выбрать зикр» → «Свой зикр»: отправьте `название | арабский текст | перевод`, либо одно название. Для произвольного круга выберите «Цель круга» → «Другое количество». Длинный список листается стрелками.

В нижней части бокового меню веба и APK есть карточка «Новости и объявления». Администратор создаёт текст, фото, GIF или видео в боте; публикация появляется в вебе, подключённом APK и по кнопке новостей в Telegram. Настройка и пошаговая инструкция: [ADMIN.md](ADMIN.md). В версии 0.5 одна текущая публикация, новая заменяет предыдущую. Массовой рассылки нет.

После обновления перезапустите локальный сервер `npm.cmd start` и бот `npm.cmd run bot` (сначала Ctrl+C в соответствующем терминале). Обновите веб Ctrl+F5. Новый сервер обязателен для расширенного каталога и API публикаций.

## Новое в 0.6

- Круг немного увеличен и опущен ниже. Размер ограничен доступной высотой, основной экран не прокручивается.
- Настройки → «Скрытый режим · часы» (также в «Тема»): чёрный экран, дата и время, тап считает выбранный зикр без отображения счёта. Выход: тусклая ☰ слева сверху → настройки или другая тема. APK снижает яркость только своего окна и удерживает экран включённым; веб запрашивает Screen Wake Lock, если браузер его поддерживает. Это экран приложения, а не настоящий системный Always-On Display; при блокировке кнопкой питания касания недоступны. Часы немного перемещаются раз в минуту.
- Вибрация: обычный тап 50 мс, завершение круга 240 мс. Следующий обычный тап не обрывает сигнал завершения. В настройках есть отдельная проверка вибрации без изменения счёта. В Telegram Mini App используются нативные medium/success-сигналы, длительность которых задаёт Telegram. В браузере, не поддерживающем Vibration API, принудительно включить вибрацию нельзя. Также учитываются возможности и настройки телефона.
- Публикации поддерживают необязательную кнопку с названием и HTTPS-ссылкой; её настраивает администратор в предпросмотре. Без обоих полей кнопка отсутствует.

Документация: [Telegram HapticFeedback](https://core.telegram.org/bots/webapps#hapticfeedback), [Android Vibrator](https://developer.android.com/reference/android/os/Vibrator), [поддержка вибрации браузерами](https://developer.mozilla.org/en-US/docs/Web/API/Vibration_API).

Для установки нижней клавиатуры Telegram требует отправить сообщение: бот оставляет одно короткое название без уведомления, чтобы нижняя клавиатура сохранялась после нажатий. Основное сообщение со счётом остаётся и обновляется.

## Обновление 0.9

В разделе «Зикры» галочки задают состав автоматического цикла, ↑/↓ меняют порядок, «Только этот» оставляет один зикр. Изменение состава включает автоматическую смену; её можно выключить в настройках. Хотя бы один зикр остаётся выбранным. Порядок и состав цикла индивидуальны для устройства, как остальные настройки практики.

Свои зикры можно удалить с подтверждением; встроенные защищены. Удаление передаётся связанным устройствам при синхронизации, старые офлайн-копии не восстанавливают удалённый зикр. Записи счёта сохраняются, в том числе ещё не отправленные. Для корректной обработки удаления обновите сервер и приложения до 0.9. В боте управление доступно через ⚙ рядом с названием.

Четвёртый переключатель в меню: 🔊 звук и вибрация (по умолчанию), 📳 только вибрация, 🔇 без обоих сигналов. Щелчок синтезируется локально и работает офлайн. Завершение круга отличается более длинным сигналом. Громкость APK регулируется громкостью мультимедиа телефона; браузер может ограничивать звук и вибрацию.

Проверено автоматическими тестами и сборкой. Звук, вибрацию и удобство касаний нужно дополнительно проверить на реальном телефоне.

## Обновление 0.10

В APK удерживайте строку зикра и перетаскивайте; в вебе удерживайте ⠿. Выше разделителя находятся участники цикла в порядке сверху вниз, ниже — остальные. Перенос через разделитель меняет участие. Хотя бы один зикр должен остаться наверху. В вебе клавиатура на ⠿ также поддерживает ↑/↓ для порядка и ←/→ для переноса между группами.

Меню оставляет 52 dp/px основного экрана справа, фон полупрозрачный. Звук заменён мягким затухающим тоном, завершение круга — двумя нотами. Android использует VibratorManager на Android 12+, обычный сигнал 75 мс, завершение 320 мс. Проверка вибрации сообщает наличие мотора и настройку вибрации касаний, позволяет открыть системные настройки. API не подтверждает фактическое ощущение вибрации.

При первом запуске без истории и привязки появляется окно «Войти через Telegram / Пропустить». Вход использует существующую защищённую привязку по одноразовому коду /link, без пароля Telegram. Пропуск сохраняется, офлайн-счёт доступен сразу.

### Рассылка администратора

/admin → Рассылка → Новая рассылка → отправить или переслать содержимое → Предпросмотр → Отправить всем. Можно собрать до 100 сообщений, в том числе альбомы. Telegram copyMessages сохраняет текстовые entities, подписи и группировку альбомов; пересланные сообщения копируются как содержимое без ссылки на исходного автора. Поддерживаются доступные Telegram для копирования текст, фото, видео, GIF, документы, аудио, голосовые, видеокружки, стикеры, контакты, геопозиции и обычные опросы. Служебные, защищённые, платные сообщения, счета, розыгрыши и некоторые викторины Telegram может запретить копировать. Неполный предпросмотр не допускается к отправке.

Очередь в SQLite сохраняется после перезапуска; получатели — пользователи бота из profiles. Есть статус, остановка, обработка 429 и недоступных адресатов. Неопределённый результат при обрыве сети или аварии помечается отдельно и не повторяется автоматически, чтобы не создавать дубликаты. Предпросмотр — снимок: изменение черновика отменяет старое подтверждение. Реальные рассылки при разработке не выполнялись.

## Обновление 0.11

- APK: ежедневное офлайн-напоминание включено по умолчанию на 07:00 по часовому поясу телефона. В настройках можно изменить время и выключить его. Android 13+ запросит разрешение уведомлений. Используется setAndAllowWhileIdle без специального доступа к точным будильникам: в режиме экономии батареи уведомление может прийти позже 07:00. После перезагрузки, смены времени и обновления приложения расписание восстанавливается.
- Настройки звука в APK и вебе: деревянные чётки, капля воды, дождь, камешки, мягкий тон. Это локально синтезированные короткие звуки, без скачивания сторонних записей. В настройках есть прослушивание, в режиме «Только вибрация» и «Тишина» счётчик их не воспроизводит.
- /admin → APK: уведомления и оформление. Уведомление: ввести текст → проверить → подтвердить. Объявления доступны сутки, повторно на том же устройстве не показываются после успешного запроса уведомления. Получение — при синхронизации: обычно при открытии или фоновой проверке, Android может откладывать её. Это не мгновенный push. Пользователь может отключить объявления отдельно от ежедневного напоминания.
- Администратор добавляет темы (название и четыре цвета с проверкой контраста) и включает тему на 1 час, 24 часа или 7 дней. По истечении срока возвращается личная тема, в том числе офлайн. Дополнительные темы доступны в обычном переключателе. Фото главного экрана и меню настраиваются отдельно, до 5 МБ; есть предпросмотр и подтверждение. APK кэширует фон локально.
- npm start / npm run bot теперь запускают бот и API вместе с общей SQLite-базой. Выберите одну команду и один процесс. Не запускайте их одновременно. Отдельный сервис API больше не нужен; бот всё ещё должен работать на компьютере/хостинге, а APK — иметь доступ к HTTPS-адресу. Токен Telegram остаётся только в .env процесса бота, не в APK.

## Версия 0.12

- APK сохраняет нажатия локально и планирует обмен после сворачивания. Максимум 5 попыток за местные календарные сутки, включая неудачные запросы; оставшаяся очередь сохраняется до следующего дня. Интернет и фоновые ограничения Android могут задержать запуск. После принудительной остановки нужно снова открыть приложение. Веб и бот используют прежнюю общую базу.
- Темы, объявления и уведомления администратора приходят с этим обменом, поэтому после исчерпания лимита могут появиться на следующий день.
- Звук, вибрация и полная тишина переключаются отдельно. В скрытом режиме только завершение круга вызывает вибрацию; полная тишина отключает и её. В конце круга используется тот же выбранный звук.
- Статистика показывает фактические количества и график за 7 дней, без ежедневной цели и заданий.
- Проверка на телефоне: установите APK поверх старой версии, проверьте сохранение истории; офлайн посчитайте, сверните, включите интернет и сравните счёт с ботом. Проверьте пять обменов и сохранение очереди после лимита. Переберите переключатели обратной связи и скрытый режим. Для вибрации должны быть разрешены вибрации касаний в системных настройках телефона.
