# Временный сервер без домена

Используется Cloudflare Quick Tunnel: HTTPS-ссылка ведёт к ZikriLLah на этом компьютере. Linux-сервер, nginx и другие боты не меняются.

## Запуск после перезагрузки компьютера

В терминалах VS Code, открытых в папке ZikriLLah:

1. Первый терминал: `npm.cmd start`. Если этот сервер уже работает, второй раз его не запускайте.
2. Второй терминал: `powershell -NoProfile -ExecutionPolicy Bypass -File scripts/start-tunnel.ps1`.
3. Дождитесь ссылки вида `https://несколько-слов.trycloudflare.com`. Скрипт запишет её в PUBLIC_URL файла .env, сохранив остальные настройки. Копия ссылки будет в .tools/public-url.txt.
4. Перезапустите только ZikriLLah-бота: Ctrl+C в его старом терминале, затем `npm.cmd run bot`. Не запускайте две копии этого бота одновременно.
5. Отправьте боту /start. Кнопка веб-приложения использует новый адрес. Ссылку можно также открыть в браузере телефона напрямую.

## Первый раз подключить Android

В APK: меню → «Подключить Telegram». Введите HTTPS-ссылку без дополнительных путей и новый код из команды /link вашего бота. Сервер и бот должны работать на этом компьютере с общим DATA_DIR. После привязки синхронизация автоматическая.

В веб-версии на новом адресе также один раз выполните привязку кодом /link. Сначала синхронизируйте несохранённые на сервере нажатия со старого адреса: localStorage привязан к адресу сайта.

## Ограничения

- Компьютер должен оставаться включённым, с интернетом; сервер и туннель должны работать. Бот тоже требует запущенного процесса. Не закрывайте нужные терминалы и не переводите ПК в сон во время проверки.
- Остановка туннеля закрывает публичный доступ. После нового запуска адрес меняется; новый адрес снова записывается в PUBLIC_URL, бот нужно перезапустить.
- APK 0.5 запоминает адрес при привязке и пока не имеет отдельной кнопки смены сервера. После смены адреса не удаляйте APK и его данные: потребуется добавить смену адреса в приложение. Этот туннель подходит прежде всего для одной непрерывной тестовой сессии.
- База и медиа остаются в папке data на компьютере. Это не перенос данных на хостинг. Публикуется только HTTP-интерфейс приложения; .env и исходники сервером не раздаются.
- Quick Tunnel предназначен для тестов, без гарантии постоянной доступности.
